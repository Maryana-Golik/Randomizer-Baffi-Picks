# 📚 Baffi Picks — Book Randomizer

**Baffi Picks** is a stylish web application designed for readers who have an extensive "To-Be-Read" (TBR) list but struggle to choose their next adventure. With its "magical" randomizer, the app makes the decision for you!

---

## ✨ Key Features
* **Bulk Book Input:** Easily paste a large list of titles in one click.
* **Interactive Grid:** A dynamic visualization of the selection process through animated book cards.
* **Smart Counter:** Real-time tracking of the total number of books in your current list.
* **Responsive Design:** Optimized for a seamless experience across all devices, from large monitors to iPhone/Android screens, thanks to custom mobile styling.
* **Elegant Aesthetic:** A premium design featuring warm beige and olive green tones with a strong focus on high-quality typography.

## 🛠 Tech Stack
In this project, I utilized:
* **HTML5** — Semantic page structure.
* **CSS3** — Advanced styling, including **Flexbox** and **CSS Grid** for layout management.
* **JavaScript (ES6+)** — Randomizer logic, DOM manipulation, and text processing (split, filter, trim).
* **Media Queries** — Ensuring a fully responsive design with a "Mobile-First" mindset and desktop adaptation.

## 📱 Mobile Optimization
Special attention was given to the mobile User Experience (UX):
- **Dynamic Grid:** The card count automatically scales down to 8 items on mobile for better visibility.
- **Vertical Layout:** Elements are reoriented for comfortable one-handed navigation.
- **Custom UI Elements:** Features bespoke dashed borders and oversized, touch-friendly buttons.
